Blocked planes are filtered out of the overhead display before any API lookups. Callsign entries match exactly — add a trailing * for a prefix match (e.g. RYR* blocks every Ryanair callsign, while RYR only blocks the literal callsign "RYR"). Registration entries (e.g. N123AB) block that airframe whether it appears by registration or flies with its registration as the callsign. Matching is case-insensitive. Changes take effect on the tracker's next poll cycle.
